# Deleting a code

Output: teacher-docs/content/30-sharing-activities/05-deleting-codes.md · order 5

Job: A teacher who wants to remove a code. After this chapter they know that deleting a
code also removes all of its data, that it is permanent, and how to do it.

Cover:
- How: select the codes you want in your list and choose Delete Selected. That is the
  only way to delete.
- What goes with it: the code stops working, and its conversations, saved student work,
  and usage statistics are all deleted.
- It is permanent, and there is no per-student delete, only per-code.

Get right:
- Deleting also removes the usage statistics, so review or export anything you need
  first.
- Codes are not removed automatically; they stay in your list until you delete them.
- Deletion is bulk-only; there is no per-row or edit-page delete.

Look: docs/codes.md (deletion and lifecycle), docs/usage-metering.md (behaviour:
deleting a code removes its statistics).
