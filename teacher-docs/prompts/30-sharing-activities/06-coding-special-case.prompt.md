Job: A teacher sharing a coding activity, which works unlike the others. After this
chapter they know the code is used as a key inside the student's coding tool, what to
give students so they can connect, and that coding is always anonymous.

Cover:
- The difference: a coding code is not a web page. The student pastes it into an
  external coding assistant as the connection key.
- What to give students: the connection details shown on the code's page (the address,
  the code as the key, and the fact that the model is already set for them), plus which
  tool to use (for example little-coder).
- What the teacher sees: overall usage only, because coding is always anonymous.

Get right:
- The code is the key; the student's tool connects with it.
- The model and instructions are set by the teacher and applied on the server, so the
  student cannot change them; describe the effect, not the mechanism.
- Always anonymous; there is no per-student data.
