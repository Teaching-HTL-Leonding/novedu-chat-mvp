# Anonymous vs. per-user

Output: teacher-docs/content/30-sharing-activities/04-anonymous-vs-per-user.md · order 4

Job: A teacher deciding whether an activity should record who did what. After this
chapter they understand what each mode means for what they can see, the default for
each kind, and that the choice is fixed when the code is created.

Cover:
- Anonymous: the app does not link work to a student, so you see counts and overall
  usage but not who did what.
- Per-user: the app records the author, so you can see who did what and open an
  individual student's work.
- The defaults by kind: tutors and quizzes are anonymous, writing is per-user, and
  coding is always anonymous.
- Where it is set: it comes from the activity and is frozen when the code is created.

Get right:
- Anonymous means you cannot tell which student did what; it is about identity.
- Changing the activity file later does not change codes that already exist.
- Making a writing activity anonymous turns off saving, because there is no author to
  save under.

Look: docs/codes.md (anonymity, frozen at creation), docs/writing.md (the writing
default and what anonymous does to saving).
