# Viewing code usage

Output: teacher-docs/content/30-sharing-activities/02-viewing-usage.md · order 2

Job: A teacher who wants to see how a code is being used. After this chapter they know,
briefly, what the code's own page and the overall usage view show. This is an
orientation, not a full dashboard manual, so keep it short.

Cover:
- On a code's page: a count of how much it has been used, and, for a per-user code, who
  did what and the ability to open individual work. A writing code shows who saved.
- The overall usage view: how much the AI has been used over time, with simple
  breakdowns (by kind, by code, by model) and a couple of totals.

Get right:
- An anonymous code shows counts but no student identities.
- A use counts only when a student actually wrote something, not when a page is merely
  opened.
- Describe what the teacher sees, not how it is stored or gated.

Look: docs/dashboard.md (behaviour), docs/codes.md (the stats and conversation-viewer
section).
