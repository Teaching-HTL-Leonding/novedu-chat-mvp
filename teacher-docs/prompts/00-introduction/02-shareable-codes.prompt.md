# What is a shareable code

Output: teacher-docs/content/00-introduction/02-shareable-codes.md · order 2

Job: A teacher who wants to understand the thing they actually hand to students. After
this chapter they know a code is a short link tied to one activity, how they get one,
what students do with it, and that a code carries a few settings decided when it is
created. Concept level; creating and editing codes has its own chapter.

Cover:
- What a code is: a short shareable link that opens one activity; you hand the link
  (or the code itself) to a class.
- How you get one: you create a code from an activity and receive a short link.
- What students do: open the link, or type the code, and get the right experience for
  that activity's kind.
- What a code carries: an optional availability window and whether it records who did
  what. Point forward to the sharing chapters for the detail.

Get right:
- You do not choose the code text; it is generated (short, random).
- One code opens one activity of one kind; the kind is fixed when the code is created.
- Coding is the exception: its code is used as a key inside an external tool, not
  opened as a web page. Mention briefly and link the coding chapters.

Look: docs/codes.md (behavioural parts only), README.md.
