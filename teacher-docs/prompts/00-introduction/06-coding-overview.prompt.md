# Coding overview

Output: teacher-docs/content/00-introduction/06-coding-overview.md · order 6

Job: A teacher deciding whether a coding activity fits their lesson. After this chapter
they understand that coding works unlike the other kinds: students use an external
coding assistant connected to Novedu with the code, and the teacher sets the
assistant's rules and model. Concept level; building and sharing are later chapters.

Cover:
- What a coding activity is: the teacher's instructions given to an external coding
  assistant that the student runs in their own coding environment.
- How it differs: there is no chat inside Novedu. The student's coding tool connects to
  Novedu using the code, and Novedu adds the teacher's instructions and chosen model.
- The student experience: set up their coding tool once with the code, then work with
  the assistant helping under the teacher's rules.
- How the teacher shapes it: describes what the class may use (language, concepts,
  style) and picks the model.
- When coding is the right kind: guided programming practice in a real editor.

Get right:
- The student uses an external assistant (for example little-coder); there is no chat
  page in Novedu.
- Coding is always anonymous; the teacher sees overall usage, not individual work.
  Mention lightly.
- The teacher's instructions and model apply on the server; students do not see them.
  Describe the effect, not the mechanism.
