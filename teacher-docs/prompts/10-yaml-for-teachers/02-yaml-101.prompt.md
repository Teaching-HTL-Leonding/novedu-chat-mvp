# YAML 101

Output: teacher-docs/content/10-yaml-for-teachers/02-yaml-101.md · order 2

Job: A teacher who needs just enough YAML to edit an activity with confidence. After
this chapter they can read and change keys, indentation, lists, and multi-line text
blocks, and avoid the common mistakes.

Cover:
- Keys and values, and when a value needs quotes.
- Indentation shows nesting: spaces, not tabs, and consistent depth.
- Lists, with each item on a line starting with "- ".
- Multi-line text with "|" for prompts and descriptions, kept exactly as typed. This
  is the part teachers write most.
- Comments with "#".

Get right:
- Use real snippets from activities/examples/**; do not invent YAML.
- Cover the traps that actually bite: tabs versus spaces, a number-looking id that must
  be quoted, and a colon inside an unquoted value.
- Teach only what appears in real activities, not the whole YAML specification.

Look: activities/examples/** (real snippets, including "|" prompt blocks), the module
READMEs' quick-start sections.
